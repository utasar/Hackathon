# Android Launcher Icons

This directory should contain launcher icons for the app.

The standard launcher icons should be placed in the following directories:
- mipmap-hdpi/ic_launcher.png (72x72 px)
- mipmap-mdpi/ic_launcher.png (48x48 px)
- mipmap-xhdpi/ic_launcher.png (96x96 px)
- mipmap-xxhdpi/ic_launcher.png (144x144 px)
- mipmap-xxxhdpi/ic_launcher.png (192x192 px)

To generate launcher icons, you can use:
1. Android Studio's Image Asset tool
2. Online tools like https://romannurik.github.io/AndroidAssetStudio/
3. Flutter's flutter_launcher_icons package

For now, the app will use the default Flutter launcher icon.
